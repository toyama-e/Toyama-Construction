## 2. 事業内容

現場の状況に合わせて、最適な進め方をご提案します。

| タイトル             | 説明文                                                                                       |
| :------------------- | :------------------------------------------------------------------------------------------- |
| **土木一式工事**     | 道路・水路・造成など、土木工事全般に対応。公共・民間を問わず幅広く請け負います。             |
| **外構工事**         | 駐車場・フェンス・門扉・舗装など。使い勝手と安全性を両立した外構を提案します。               |
| **改修・修繕**       | 老朽化した構造物の補修・修繕に対応。現地確認を行い、最適な工法で丁寧に施工します。           |
| **小規模リフォーム** | 部分的なリフォームや住宅周りの改善工事もお任せください。お困りごとをスピーディに解決します。 |

## 3. 選ばれる理由

地域のお客様に長く選ばれ続ける、3つの強みをご紹介します。

| タイトル                     | 説明文                                                                                 |
| :--------------------------- | :------------------------------------------------------------------------------------- |
| **他社より安く、柔軟に対応** | 小さな工事・急な依頼もOK。無駄な中間マージンを省き、適正価格でお応えします。           |
| **土木から外構まで一式対応** | 道路・水路・外構・改修を一手に引き受け。窓口がひとつで完結するので手間がかかりません。 |
| **新潟県央エリア密着**       | 地元をよく知るスタッフが現地確認から施工まで担当。スピーディな対応が自慢です。         |
