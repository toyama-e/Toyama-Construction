# 外山建設コーポレートサイト テスト計画

## 1. ユニットテスト（コンポーネント単体）

**ツール: Jest + React Testing Library**

### 共通コンポーネント

| テスト対象 | 確認内容 |
| --- | --- |
| `Header` | `variant="lp"` と `variant="recruit"` でナビ項目が切り替わる |
| `Header` | 電話番号・採用ボタンが表示される |
| `Footer` | 会社名・住所・電話番号が `company.ts` の値と一致する |

### LP コンポーネント

| テスト対象 | 確認内容 |
| --- | --- |
| `Hero` | キャッチコピーと CTA ボタンが表示される |
| `Services` | 4項目のカードが全て表示される |
| `License` | 許可番号・資格・保険が表示される |
| `About` | 会社概要テーブルの項目（住所・電話・営業時間等）が表示される |
| `Contact` | 電話番号・メール・フォームリンクが正しい href を持つ |

### 採用コンポーネント

| テスト対象 | 確認内容 |
| --- | --- |
| `Apply` | 応募フォームリンクが正しい href を持つ、`target="_blank"` と `rel="noopener noreferrer"` がある |
| `JobSpec` | 給与・勤務時間・休日が正しく表示される |
| `Faq` | Q&A が全件表示される |

## 優先順位

| 優先度 | テスト種別 |
| --- | --- |
| 高 | 定数テスト・Contact/Apply の href 検証（リンク切れ防止） |
| 中 | コンポーネントの表示テスト・スナップショット |
| 低 | アクセシビリティ・E2E（品質向上フェーズで追加） |
