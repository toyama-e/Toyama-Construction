# 外山建設コーポレートサイト テスト計画

Version 2.0　更新日：2026年7月31日

## 方針

静的サイトで壊れやすい問い合わせ導線と会社情報を自動テストし、表示品質は複数画面幅で手動確認します。ビルド成功も公開前の必須確認に含めます。

## 自動テスト

ツールはVitestとTesting Libraryです。現在は4ファイル、11項目を実行します。

| 対象          | 確認内容                                                                         |
| ------------- | -------------------------------------------------------------------------------- |
| `company.ts`  | FAX、メール、LINE通話URL、LINE友だち追加URLの形式                                |
| `Contact.tsx` | LINE通話・友だち追加リンクのURLと外部リンク設定、メールをContactに表示しないこと |
| `Footer.tsx`  | メールリンクが `mailto:` 形式であること                                          |
| `Apply.tsx`   | LINE通話・友だち追加の外部リンク設定、メールリンクが `mailto:` 形式であること    |

```bash
npm test -- --run
```

## 静的検査・ビルド

```bash
npm run lint
npm run build
```

静的エクスポートが成功し、`/`、`/company`、`/recruit` が生成されることを確認します。

## 手動表示確認

次の順で確認します。

1. 375px：基本のスマートフォン表示
2. 320px：横スクロール、重なり、ボタンのはみ出し
3. 390px：iPhone 14相当
4. 430px：大きめ端末の余白
5. 768px：レイアウト切り替え
6. 1024px、1440px：PC表示

合わせて次を確認します。

- ハンバーガーメニューを開閉できる
- ヘッダーとフッターのページ内リンクが、実際のセクション名とアンカー先に一致する
- 固定ヘッダーが見出しやアンカー先を隠さない
- 主要CTAのタップ領域が44px以上ある
- LINE通話、LINEチャット、メールが正しい宛先を開く
- スマートフォンではQRコードが非表示になる
- 写真・ロゴ・QRコード・OGP画像の参照先が存在する
- `prefers-reduced-motion` で自動アニメーションが実質停止する
- iPhone Safari、Android Chrome、PCブラウザで読める
