# 外山建設コーポレートサイト テスト計画

Version 1.1　作成日：2026年6月6日

## 方針

このサイトは静的コンテンツのコーポレートサイトのため、テストは「自動でないと検知できないリスク」に絞る。
ビルド失敗は Cloudflare Pages が自動検知するため、テスト対象から除外する。

---

## テスト対象（全5項目）

**ツール: Vitest**

| テスト対象    | 確認内容                                                               |
| ------------- | ---------------------------------------------------------------------- |
| `company.ts`  | `tel` が `0000-00-0000` 形式である                                     |
| `company.ts`  | `email` に `@` が含まれる                                              |
| `company.ts`  | `lineUrl` が `https://` で始まる                                       |
| `Contact.tsx` | LINE・メールの `href` 属性が正しい値を持つ                             |
| `Apply.tsx`   | 応募先リンクに `target="_blank"` と `rel="noopener noreferrer"` がある |

---

## 今はやらないこと

| 種別                               | 理由                                                      |
| ---------------------------------- | --------------------------------------------------------- |
| スナップショットテスト             | JSX を変更するたびに更新するだけになり形骸化する          |
| コンポーネントのレンダリングテスト | ブラウザで確認すれば十分。テストの情報量が低い            |
| jest-axe（アクセシビリティ）       | セットアップが複雑。Lighthouse での手動チェックで代替する |
| E2E テスト                         | コンテンツと UI が固まったフェーズ2で導入する             |
