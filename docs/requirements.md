# 株式会社 外山建設 ホームページ要件定義書

Version 2.0　更新日：2026年7月31日

## 1. 目的

優先順位は次の通りです。

1. 作業員を1名採用する
2. 工事の相談・依頼を獲得する
3. 小さな会社ならではの親しみやすさ、安心感、人柄を伝える

採用の主なターゲットは20代〜40代程度の男性です。工事相談では個人宅への対応が伝わるよう「ご自宅の」という表現を残します。

## 2. 基本方針

- スマートフォンでの閲覧を最優先する
- 華やかにしすぎず、写真と余白を活かす
- 社長と役員の顔が見える、入りやすい小さな会社として表現する
- トップページは情報を詰め込まず、詳細は会社案内・採用ページへ分ける
- 未確定情報を推測で補わず、Mockまたは確認中として扱う

## 3. ページ構成

### `/`

1. Header
2. Hero
3. Services
4. CompanyIntro
5. RecruitIntro
6. Contact
7. Footer

トップページは「何をする会社か」「どんな人が働くか」「採用中であること」「相談方法」が短時間で分かる構成にします。

### `/company`

1. Header
2. Hero
3. WhyUs
4. About
5. License
6. Contact
7. Footer

3つの強み、会社概要、所在地、Googleマップ、建設業許可、保有資格、加入保険を掲載します。

### `/recruit`

1. Header
2. Hero
3. JobSpec
4. Promise
5. DailySchedule
6. Message
7. Faq
8. Apply
9. Footer

ファーストビューに未経験歓迎、給与、勤務地、勤務時間、応募CTAをまとめます。

施工実績は将来追加予定で、現時点では実装しません。

## 4. 問い合わせ・応募

- 一般公開する固定電話番号は設けない
- LINE通話を電話窓口として扱う
- 優先順位はLINE通話、LINEチャット、メール
- トップページのContactにはLINE通話とLINEチャットだけを表示する
- メールは全ページ共通フッターにテキストリンクで表示する
- 採用ページのApplyにはLINE通話、LINEチャット、メールを表示する
- スマートフォンではQRコードを隠し、タップできるボタンを優先する
- PCではLINE通話と友だち追加のQRコードを表示できる
- 外部リンクには `target="_blank"` と `rel="noopener noreferrer"` を設定する
- FAX番号を電話番号として案内せず、`tel:` リンクを作らない

トップページContactの文言は次の通りです。

> LINEで気軽にご相談いただけます
>
> 直接話せるLINE通話がおすすめです。<br>
> 文章や写真は、LINEチャットから送れます。

## 5. デザイン

| 用途       | 色                 | コード    |
| ---------- | ------------------ | --------- |
| 背景       | ホワイト           | `#FFFFFF` |
| 主要CTA    | ディープネイビー   | `#17233A` |
| 本文       | チャコールネイビー | `#202734` |
| 区切り     | 淡いブルーグレー   | `#F2F7FA` |
| 中間色     | ペールブルー       | `#F7FAFC` |
| 終端色     | ライトブルー       | `#E7F0F5` |
| 補助文     | ブルーグレー       | `#626A75` |
| アクセント | マットブロンズ     | `#955F3A` |

- 白約75%、淡いブルーグレー約15%、ネイビー約8%、ブロンズ約2%を目安にする
- ゴールドや鮮やかなオレンジは使わない
- LINEボタンのみ公式グリーンを使う
- 見出しはNoto Serif JP、本文はゴシック体を使う
- Hero、Services、CompanyIntro、RecruitIntroは、大きな写真に暗いグラデーションを重ね、白いラベルと短い見出しを載せる
- 写真上のラベル前の横線は白にする
- 長い説明文とCTAは写真の下へ分ける
- Services、CompanyIntro、RecruitIntroの写真は本番素材が揃うまで単色のPHOTO MOCKとする

## 6. スマートフォン表示

- 375pxを基本、320pxを最小確認幅とする
- 主要リンク・ボタンは44px × 44px以上を目安にする
- 1024px未満のヘッダーはハンバーガーメニューを使用し、768pxでPCナビゲーションへ切り替えない
- 各ページのヘッダーとフッターのページ内ナビゲーションは、実際のセクション名・掲載順・アンカーIDと一致させる
- ヘッダーとフッターは共通のナビゲーション定義を使い、ページごとの主要メニューと強調CTAを一致させる
- 採用ページのヘッダーナビゲーションは「募集要項」「入社後の2つの約束」「1日の流れ」「代表より」「よくある質問」とする
- 画面下を固定CTAで塞がない
- 不自然な折り返しは、文章の短縮、本文幅、文字サイズ・行間、意味の切れ目での改行の順に調整する
- 320px、375px、390px、430px、768px、1024px、1440pxで確認する
- フッターは中央揃えのロゴ・住所・メール、ページ別ナビゲーション、強調CTA、独立したプライバシーポリシーリンク、著作権表示で構成する
- スマートフォンのフッターナビゲーションは3項目を基本の1段とし、残りの項目も行単位で中央揃えにして上下余白を抑える
- トップページのフッターナビゲーションは文字量に応じた幅で中央配置し、375px以上では「外山建設について」を1行で表示する
- トップページのフッターにある「採用情報を見る」CTAは、1024px以上でもページ別ナビゲーションの中央に揃える
- 会社案内ページのフッターにある「採用情報を見る」CTAも、1024px以上でページ別ナビゲーションの中央に揃える
- 会社案内・採用ページのフッターナビゲーションは768px以下で2列を基本とし、「許可・資格・保険」と「入社後の2つの約束」を1行で表示する
- 会社案内ページのフッターナビゲーションは1024px以上で4列1段とし、4項目をすべて1行に収める。採用ページは1024px以上で3列に戻す
- 会社案内ページの1024px以上のフッターは、4項目を等幅の列内で中央揃えにして均等な間隔を確保し、「採用情報を見る」CTAも4項目全体の中央線に揃える
- 採用ページのフッターで最終行に「よくある質問」だけが残る場合は、上の項目と列を揃えて左側へ配置する
- 768px以上のフッターは会社情報を左、ナビゲーションを右に置く2カラム構成にする
- フッターにはContactと重複するLINE通話、受付時間、FAX、LINE IDを表示しない
- トップページの説明文にある手動改行はスマートフォンだけに適用し、768px以上では文章を自然につなげる
- 320pxでは文字を小さくせず、ヒーロー、事業内容、問い合わせの説明を意味の切れ目で追加改行する
- 320pxの問い合わせ見出しは「LINEで気軽に／ご相談いただけます」と2行で表示する
- 768px以上では「ご相談から施工まで、一つひとつ丁寧に対応します。」を途中改行しない
- 会社案内ページは375pxを基本表示とし、320pxと375pxでは説明文を読点・句点で改行する。会社概要の見出しは写真へ重ね、会社概要表はスマートフォンで項目名と内容を縦積みにする
- 会社概要表の会社名は「外山」の真上にだけ「とやま」のルビを表示し、住所と代表者名には振り仮名を付けない
- 768〜1023pxの会社概要表は項目名の列幅と左右余白を抑え、所在地・事業内容・定休日を1行で表示する。1024px以上の表レイアウトは維持する
- 3つの強みの1番・2番のタイトルは320pxでは2行、375px以上では1行で表示する
- 3つの強みは768〜1023pxでは縦並び、1024px以上では横3列とし、横3列時のタイトルはすべて1行で表示する
- 建設業許可番号は会社概要表に重複掲載せず、「許可・資格・保険」に集約する
- 許可・資格・保険は768〜1023pxでは見出しを左、内容を右に置く縦3段とし、許可番号と資格名を1行で表示する。1024px以上では横3列を維持する
- 768px以上のお問い合わせカードでは、LINE通話と友だち追加のボタンを同じ幅・高さにし、QRコードを同じ120px角で表示する
- リクルートページは、約束・FAQ・代表メッセージを768〜1023pxでは縦並びにし、1024px以上で横並びへ切り替える。募集要項と1日の流れは768px以上で読みやすい本文幅に制限する
- リクルートページの応募欄は、768px以上でLINE通話・LINEチャットを2列にし、その下へ横長の「メールで応募する」ボタンを配置する。LINE系のボタンとQRコードは左右同じ寸法にする
- リクルートページは「1日の流れ」の直後に固定表示ではないコンパクトな応募CTAを置き、ページ末尾の応募方法へ誘導する
- リクルートページの375px表示は、Hero、募集要項、2つの約束、1日の流れ、代表メッセージ、FAQ、応募案内を句点・読点など意味の切れ目で改行する。768px以上では手動改行を解除する
- リクルートページの320px表示では、募集要項を項目名が上・内容が下の1カラムにし、360px以上では2カラムへ戻す。Heroは「小さな会社だからこそ、」の後、募集見出しは「現場スタッフ」「（正社員）」「募集要項」の3行にする
- 320pxの募集要項は、項目名を13pxのブロンズ太字、内容を15pxのチャコールネイビーにし、項目間を細い罫線で区切る。360px以上は従来の表示へ戻す
- 昼休憩は「昼休憩（1時間・作業により前後あり）」と表記し、320pxでは補足を13pxの1行で表示する。代表メッセージの本文は前半・後半で同じ文字サイズにする
- 320pxでは代表メッセージとFAQの強制改行を増やしすぎず、簡潔な文章の自然な折り返しを優先する。応募見出しは「まずはLINEで／話してみませんか？」の2行にする
- 375pxの応募案内は「『まだ迷っている』『話だけ聞きたい』／そんな方も大歓迎です。」と表示し、「でも」を行頭に置かない
- 1つ目の強みは「小さな工事・急な依頼もOK。／中間コストを抑え、適正価格で対応します。」の2行とする
- 2つ目の強みは「道路・水路・外構・改修まで対応。／相談から施工まで、窓口ひとつで完結します。」の2行とする
- 3つ目の強みは「地元スタッフが現地確認から施工まで担当。／スピーディな対応が自慢です。」の2行とする

## 7. 会社情報

- 建設業許可：新潟県知事許可（般-4）第46299号
- 加入保険：建設工事保険、労働者災害補償保険
- Googleマップ：APIキー不要のiframe埋め込み
- 再利用する会社情報：`src/constants/company.ts` を唯一の情報源とする
- JSON-LD：固定電話の `telephone` は設定せず、FAXを掲載する場合は `faxNumber` を使う

## 9. SEO

- 各ページに内容に合うtitleとdescriptionを設定する
- OGP画像は実在する `/images/og-image.jpg` を参照する
- 本番ドメイン確定後、metadata、Open Graph、sitemap、robots、JSON-LDのURLを更新する
- 本番ドメイン未確定の間は `NEXT_PUBLIC_SITE_URL` または仮URLを使用する

## 10. プライバシー

LINEとメールで氏名、連絡先、応募内容、工事相談内容を受け取るため、`/privacy` にプライバシーポリシーを掲載し、全ページのフッターからリンクします。

- 利用目的、第三者提供、業務委託、安全管理、開示・訂正・利用停止等の窓口を記載する
- 工事に必要な場合は、必要最小限の情報を協力会社または業務委託先へ共有する可能性がある
- LINE通話は録音しない
- 不採用者の情報は、選考終了後、保管の必要がなくなり次第速やかに削除または廃棄する
- 採用者の情報は雇用管理に必要な範囲で利用する
- アクセス解析を導入する場合は、利用サービスとCookie等の取り扱いを追記する
