# 株式会社 外山建設 ホームページ要件定義書

Version 2.0　更新日：2026年7月31日

## 1. 目的

優先順位は次の通りです。

1. 作業員を1名採用する
2. 工事の相談・依頼を獲得する
3. 小さな会社ならではの親しみやすさ、安心感、人柄を伝える

採用の主なターゲットは20代〜40代程度の男性です。工事相談では個人宅への対応が伝わるよう「ご自宅の」という表現を残します。

## 2. 基本方針

- スマートフォンでの閲覧を最優先する
- 華やかにしすぎず、写真と余白を活かす
- 社長と役員の顔が見える、入りやすい小さな会社として表現する
- トップページは情報を詰め込まず、詳細は会社案内・採用ページへ分ける
- 未確定情報を推測で補わず、Mockまたは確認中として扱う

## 3. ページ構成

### `/`

1. Header
2. Hero
3. Services
4. CompanyIntro
5. RecruitIntro
6. Contact
7. Footer

トップページは「何をする会社か」「どんな人が働くか」「採用中であること」「相談方法」が短時間で分かる構成にします。

### `/company`

1. Header
2. Hero
3. WhyUs
4. About
5. License
6. Contact
7. Footer

3つの強み、会社概要、所在地、Googleマップ、建設業許可、保有資格、加入保険を掲載します。

### `/recruit`

1. Header
2. Hero
3. JobSpec
4. Promise
5. DailySchedule
6. Message
7. Faq
8. Apply
9. Footer

ファーストビューに未経験歓迎、給与、勤務地、勤務時間、応募CTAをまとめます。

施工実績は将来追加予定で、現時点では実装しません。

## 4. 問い合わせ・応募

- 一般公開する固定電話番号は設けない
- LINE通話を電話窓口として扱う
- 優先順位はLINE通話、LINEチャット、メール
- トップページのContactにはLINE通話とLINEチャットだけを表示する
- メールは全ページ共通フッターにテキストリンクで表示する
- 採用ページのApplyにはLINE通話、LINEチャット、メールを表示する
- スマートフォンではQRコードを隠し、タップできるボタンを優先する
- PCではLINE通話と友だち追加のQRコードを表示できる
- 外部リンクには `target="_blank"` と `rel="noopener noreferrer"` を設定する
- FAX番号を電話番号として案内せず、`tel:` リンクを作らない

トップページContactの文言は次の通りです。

> LINEで気軽にご相談いただけます
>
> 直接話せるLINE通話がおすすめです。<br>
> 文章や写真は、LINEチャットから送れます。

## 5. デザイン

| 用途       | 色                 | コード    |
| ---------- | ------------------ | --------- |
| 背景       | ホワイト           | `#FFFFFF` |
| 主要CTA    | ディープネイビー   | `#17233A` |
| 本文       | チャコールネイビー | `#202734` |
| 区切り     | 淡いブルーグレー   | `#F2F7FA` |
| 中間色     | ペールブルー       | `#F7FAFC` |
| 終端色     | ライトブルー       | `#E7F0F5` |
| 補助文     | ブルーグレー       | `#626A75` |
| アクセント | マットブロンズ     | `#955F3A` |

- 白約75%、淡いブルーグレー約15%、ネイビー約8%、ブロンズ約2%を目安にする
- ゴールドや鮮やかなオレンジは使わない
- LINEボタンのみ公式グリーンを使う
- 見出しはNoto Serif JP、本文はゴシック体を使う
- Hero、Services、CompanyIntro、RecruitIntroは、大きな写真に暗いグラデーションを重ね、白いラベルと短い見出しを載せる
- 写真上のラベル前の横線は白にする
- 長い説明文とCTAは写真の下へ分ける
- Services、CompanyIntro、RecruitIntroの写真は本番素材が揃うまで単色のPHOTO MOCKとする

## 6. スマートフォン表示

- 375pxを基本、320pxを最小確認幅とする
- 主要リンク・ボタンは44px × 44px以上を目安にする
- 1024px未満のヘッダーはハンバーガーメニューを使用し、768pxでPCナビゲーションへ切り替えない
- 画面下を固定CTAで塞がない
- 不自然な折り返しは、文章の短縮、本文幅、文字サイズ・行間、意味の切れ目での改行の順に調整する
- 320px、375px、390px、430px、768px、1024px、1440pxで確認する
- フッターは中央揃えのロゴ・住所・メール、3列2段のナビゲーション、著作権表示で構成する
- スマートフォンのフッターナビゲーションは、1段目の3項目と2段目の2項目をそれぞれ独立して中央揃えにし、上下余白を抑える
- 768px以上のフッターは会社情報を左、ナビゲーションを右に置く2カラム構成にする
- フッターにはContactと重複するLINE通話、受付時間、FAX、LINE IDを表示しない
- トップページの説明文にある手動改行はスマートフォンだけに適用し、768px以上では文章を自然につなげる
- 320pxでは文字を小さくせず、ヒーロー、事業内容、問い合わせの説明を意味の切れ目で追加改行する
- 320pxの問い合わせ見出しは「LINEで気軽に／ご相談いただけます」と2行で表示する
- 768px以上では「ご相談から施工まで、一つひとつ丁寧に対応します。」を途中改行しない

## 7. 会社情報

- 建設業許可：新潟県知事許可（般-4）第46299号
- 加入保険：建設工事保険、労働者災害補償保険
- Googleマップ：APIキー不要のiframe埋め込み
- 再利用する会社情報：`src/constants/company.ts` を唯一の情報源とする
- JSON-LD：固定電話の `telephone` は設定せず、FAXを掲載する場合は `faxNumber` を使う

## 8. 確認中・Mock

- 本番ドメイン：未取得
- 保有資格：Mock
- 採用条件・募集要件：一部を除きMock
- 施工対応地域の具体的な市町村名：確認中

## 9. SEO

- 各ページに内容に合うtitleとdescriptionを設定する
- OGP画像は実在する `/images/og-image.jpg` を参照する
- 本番ドメイン確定後、metadata、Open Graph、sitemap、robots、JSON-LDのURLを更新する
- 本番ドメイン未確定の間は `NEXT_PUBLIC_SITE_URL` または仮URLを使用する

## 10. プライバシー

LINEとメールで氏名、連絡先、応募内容、工事相談内容を受け取るため、公開前にプライバシーポリシーを用意します。利用目的、第三者提供、安全管理、開示・訂正・削除の窓口を記載します。

## 11. 技術・運用

- Next.js App Router / TypeScript / Tailwind CSS
- 静的エクスポート
- Vitest / Testing Library
- ESLint / Prettier
- Cloudflare Pagesでの公開を予定
- `develop` で作業し、GitHubの `develop` へpushする
- Pull Requestは `develop` から `main` に向ける
