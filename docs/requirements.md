## 3. ターゲットユーザー分析（採用）

採用における主なターゲットは **20〜40代男性** とする。

### 行動特性

- スマホで仕事の合間・帰り道に閲覧する
- 感情よりも**現実（給与・待遇・職場環境）**で判断する
- 「三条市 建設会社 求人」「新潟 土木 正社員」「県央 外構 未経験」などで検索する

### 刺さる訴求ポイント（優先順）

1. **カネ**　— 給料・待遇が一目でわかること
2. **人間関係**　— 職場の雰囲気・少人数感
3. **将来性**　— スキルが身につくか・安定しているか

### コピーの原則

曖昧な言葉を排除し、**数字と具体**に変える。

| ❌ よくある書き方      | ✅ 刺さる書き方                              |
| ---------------------- | -------------------------------------------- |
| 「やる気のある方歓迎」 | 「未経験でも3ヶ月で現場に出られます」        |
| 「アットホームな職場」 | 「社員3名。社長と毎日話せる距離感」          |
| 「各種社会保険完備」   | 「健康保険・厚生年金・雇用保険・労災完備」   |
| 「給与は経験考慮」     | 「月給22万〜（前職の給与を考慮します）」     |
| 「土木の仕事です」     | 「地元の道路・駐車場・家を自分の手でつくる」 |

## 5. 機能要件

### 5-1. ナビゲーション

- ヘッダーに固定ナビゲーション（各セクションへのアンカーリンク）
- 「電話する」ボタン：tel:リンクでスマホから直接電話可能
- 「採用応募」ボタン：採用セクションへスクロール
- スマホ時はハンバーガーメニューを採用

### 5-2. お問い合わせ

- Googleフォームを別タブで開くリンクボタン
- 将来的に独自フォーム（Resend等）に置き換え可能な設計

### 5-3. レスポンシブ対応

- PC・タブレット・スマートフォン全てに対応
- スマホ最優先で設計する（ターゲットがスマホで閲覧するため）
- ファーストビューに給与と「未経験OK」を含める

### 5-4. Googleマップ埋め込み

- 会社概要セクションに Google Maps Embed を設置
- 所在地（新潟県三条市西潟14-23）を表示
- Embed APIを使用（無料）

### 5-5. 許可・資格・保険の明示

- 建設業許可番号を明記（仮→実際の番号に差し替え）
- 加入保険（工事保険等）を記載
- 取得資格があれば一覧表示
- 「信頼できる業者か」を確認したいユーザーが必ず見るセクション

### 5-6. 採用セクション レイアウト

```
┌─────────────────────────────────┐
│  採用情報                         │
│  少人数だからこそ、早く成長できる。  │
├─────────────────────────────────┤
│  ✅ 月給22万〜（経験考慮）          │ ← 数字を大きく・最初に
│  ✅ 未経験歓迎・丁寧に教えます      │
│  ✅ 社会保険完備                   │
├──────────┬────────────────────┤
│ こんな人と  │ 現場スタッフ 3名      │ ← 少人数をプラスに
│ 働きます    │ 20〜40代・アットホーム │
├──────────┴────────────────────┤
│  【1日の流れ】                     │ ← 具体的に見せる
│  7:45 朝礼 → 8:00 現場へ         │
│  12:00 昼休憩 → 17:00 終業       │
├─────────────────────────────────┤
│  ┌──────────┐ ┌──────────┐   │
│  │ 応募・相談する │ │ 電話で応募  │   │
│  └──────────┘ └──────────┘   │
└─────────────────────────────────┘
```

### 5-7. 画像管理

- `/public/images/` フォルダに格納（外部ストレージは使用しない）
- 画像は事前にSquoosh等で圧縮し、1枚あたり200KB以下を目安とする
- Next.jsの `<Image>` コンポーネントを使用して最適化

## 6. SEO・集客戦略

### 検索キーワード対策

以下のキーワードをページ内の自然な文章に盛り込む。

- 「三条市 建設会社 求人」
- 「新潟 土木 正社員」
- 「県央 外構 未経験」
- 「燕三条 建設 採用」
- 「○○市 外構工事」（対応エリアの市町村名を複数記載）

> **ポイント：市町村名は必ず入れる**。地名があるだけで地域検索に引っかかりやすくなる。

### Googleビジネスプロフィール（最優先・無料）

サイト公開前後に必ず登録する。

- Googleマップ上に会社情報・写真・営業時間が表示される
- 「三条市 建設会社」で地図検索に出てくる
- 完全無料・スマホから管理可能

|        | Googleビジネスプロフィール | サイト内Googleマップ埋め込み |
| ------ | -------------------------- | ---------------------------- |
| 役割   | 検索・地図で見つけてもらう | 会社の場所を伝える           |
| コスト | 無料                       | 無料（Embed API）            |
| 優先度 | 🔴 最優先                  | 🟡 あると良い                |

## 7. 技術構成

| 項目           | 採用技術・サービス           | 理由                           |
| -------------- | ---------------------------- | ------------------------------ |
| フロントエンド | Next.js（静的生成）          | 学習中の技術・SEOに強い        |
| スタイリング   | Tailwind CSS                 | シンプルで保守しやすい         |
| コード管理     | GitHub                       | バージョン管理・無料           |
| ホスティング   | Cloudflare Pages             | 無料・商用OK・高速CDN          |
| 独自ドメイン   | お名前.com 等                | 約1,500円/年                   |
| お問い合わせ   | Googleフォーム（外部リンク） | 実装コスト0・将来置換可能      |
| メール         | 未定（Zoho無料枠 等）        | 会社メールアドレスが必要な場合 |
| 地図           | Google Maps Embed API        | 無料・会社概要に埋め込み       |

### 開発環境

- ローカル環境で開発（Docker不使用・一人開発のため不要）
- `npm run dev` でローカルサーバー起動
- `git push` → Cloudflare Pagesが自動デプロイ

## 8. 非機能要件

### パフォーマンス

- Lighthouseスコア：Performance 90以上を目標
- 画像はNext.js Imageコンポーネントで自動最適化

### SEO

- 各ページに title・description のメタタグを設定
- 静的生成（SSG）によりクローラーがHTMLを直接取得可能
- 地域名キーワードを自然な文章に含める

### セキュリティ

- Cloudflare経由でDDoS対策・SSL自動適用
- お問い合わせはGoogleフォームのため、個人情報をサーバーに保存しない

### スマホ対応

- スマホ最優先で設計・テスト
- 電話ボタンはワンタップで発信できる `tel:` リンク
- 応募フォームの入力項目は最小限（名前・電話番号のみでも可）
