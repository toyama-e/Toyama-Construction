# 株式会社 外山建設 ホームページ 非機能要件

Version 2.1　更新日：2026年8月18日

## 1. パフォーマンス

- Next.jsの静的エクスポートを維持する
- 写真は原則WebPまたはAVIFとし、1枚200KB以下を目安に事前圧縮する
- 静的エクスポートでは画像のサーバー側最適化に依存しない
- LCP対象画像は特に軽量化し、適切な幅・高さを指定する
- JavaScriptによる装飾を増やしすぎず、CSS中心の控えめな動きにする
- 公開前後にLighthouseとSearch ConsoleのCore Web Vitalsで確認する

目標値はLCP 2.5秒以内、CLS 0.1未満、INP 200ms以内を目安とします。

## 2. 可用性・配信

- Cloudflare Pagesで運用し、Production branchは `main` とする
- 本番ドメインは `https://toyama-kensetsu.com`（wwwなし）とする
- 公開設定完了後はGitHubの対象ブランチから静的ファイルを配信する
- デプロイ失敗時は直前の正常なデプロイへ戻せる状態にする
- 公開後に稼働監視の導入を検討する

## 3. セキュリティ

- 秘密情報をリポジトリへ保存しない
- 現在のGoogleマップはAPIキー不要のiframeを使う
- 外部リンクを新しいタブで開く場合は `rel="noopener noreferrer"` を付ける
- ユーザー入力フォームを設置しないため、問い合わせ情報をサイト内で保存しない
- 依存パッケージとビルド結果を定期的に確認する
- 公開時はHTTPSを必須とする

## 4. プライバシー

LINEまたはメールで氏名、連絡先、応募内容、工事相談内容を受け取るため、`/privacy` に次を含むプライバシーポリシーを掲載します。

- 取得する情報
- 利用目的
- 第三者提供
- 安全管理
- 開示・訂正・削除
- 問い合わせ窓口

全ページのフッターからリンクし、協力会社への必要最小限の共有、LINE通話を録音しないこと、不採用者情報を選考終了後に速やかに削除または廃棄することを明記します。

Google Analytics 4とCookie等の利用目的、収集する情報、無効化方法、Google公式のデータ利用説明へのリンクをプライバシーポリシーに掲載します。運用方針とCookie同意バナーの再検討条件は `docs/analytics-operations.md` で管理します。

## 5. アクセシビリティ

- 正しい見出し順とセマンティックなHTMLを使用する
- 画像には用途に合う `alt` を設定し、装飾画像は空の `alt` とする
- リンク、ボタン、フォーム部品などは、キーボード操作時に3pxのブロンズ枠と3pxの間隔を共通表示し、フォーカス位置が分かるようにする
- QRコードは直前のLINEボタンと同じリンク先を重複させず、キーボードのフォーカス対象にしない
- フッターの会社ロゴは、ヘッダーのロゴやページ内ナビゲーションと移動先が重複するためリンクにせず、キーボードのフォーカス対象にしない
- 採用ページは応募欄の「メールで応募する」と重複するため、フッターの「メールで問い合わせる」を表示しない
- 埋め込みGoogleマップはキーボードのフォーカス順から外し、代わりに「Googleマップで開く」外部リンクを地図の直下へ表示する
- 本文と背景は原則4.5:1以上のコントラストを確保する
- 色だけで意味を伝えない
- 主要リンクとボタンは44px × 44px以上を目安にする
- hoverだけに依存しない
- `prefers-reduced-motion` を尊重し、自動アニメーションを実質停止できるようにする

## 6. レスポンシブ・対応環境

スマートフォンを最優先とします。

| 幅              | 用途                         |
| --------------- | ---------------------------- |
| 320px           | 最小幅、はみ出し・重なり確認 |
| 375px           | 基本レイアウト               |
| 390px           | iPhone 14相当                |
| 430px           | 大きめスマートフォン         |
| 768px           | 切り替え地点                 |
| 1024px / 1440px | PC                           |

公開前にiPhone Safari、Android Chrome、PC版ChromeまたはSafariで確認します。

## 7. SEO・共有

- 各ページに固有のtitleとdescriptionを設定する
- OGPは実在する `/images/og-image.jpg` を使用する
- LocalBusiness JSON-LDに固定電話の `telephone` を設定しない
- FAXを構造化する場合は `faxNumber` を使用する
- metadata、Open Graph、sitemap、robots、JSON-LDのURLは `https://toyama-kensetsu.com` に統一する
- 公開後にGoogle Search Consoleへ登録する

## 8. 保守性

- 会社情報は `src/constants/company.ts` に集約する
- 1ファイル1コンポーネントを基本とする
- TypeScriptとTailwind CSSの既存構成を維持する
- 未確定情報をコードや文書で事実として補わない
- 変更後はテスト、Lint、ビルドを実行する
- `AGENTS.md`、README、要件定義、掲載文書が実装と食い違わないように更新する

## 9. 計測

現在の独自計測イベントは次の通りです。

| イベント              | 対象                             |
| --------------------- | -------------------------------- |
| `line_call_click`     | LINE通話ボタン                   |
| `line_chat_click`     | LINEチャット・友だち追加ボタン   |
| `email_click`         | メールリンク                     |
| `recruit_page_click`  | 採用ページへの移動               |
| `recruit_apply_click` | 採用ページ内の応募欄へ進むボタン |

Google Signalsと広告パーソナライズは無効にし、データ保持期間は2か月とします。氏名、電話番号、メールアドレス、LINEの会話内容、応募内容等の個人を特定できる情報をGA4へ送信しません。詳細は `docs/analytics-operations.md` を参照します。
