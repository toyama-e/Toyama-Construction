# 株式会社 外山建設 ホームページ 非機能要件

Version 2.0　更新日：2026年7月31日

## 1. パフォーマンス

- Next.jsの静的エクスポートを維持する
- 写真は原則WebPまたはAVIFとし、1枚200KB以下を目安に事前圧縮する
- 静的エクスポートでは画像のサーバー側最適化に依存しない
- LCP対象画像は特に軽量化し、適切な幅・高さを指定する
- JavaScriptによる装飾を増やしすぎず、CSS中心の控えめな動きにする
- 公開前後にLighthouseとSearch ConsoleのCore Web Vitalsで確認する

目標値はLCP 2.5秒以内、CLS 0.1未満、INP 200ms以内を目安とします。

## 2. 可用性・配信

- Cloudflare Pagesでの公開を予定するが、現時点では未運用
- 本番ドメインも未取得
- 公開設定完了後はGitHubの対象ブランチから静的ファイルを配信する
- デプロイ失敗時は直前の正常なデプロイへ戻せる状態にする
- 公開後に稼働監視の導入を検討する

## 3. セキュリティ

- 秘密情報をリポジトリへ保存しない
- 現在のGoogleマップはAPIキー不要のiframeを使う
- 外部リンクを新しいタブで開く場合は `rel="noopener noreferrer"` を付ける
- ユーザー入力フォームを設置しないため、問い合わせ情報をサイト内で保存しない
- 依存パッケージとビルド結果を定期的に確認する
- 公開時はHTTPSを必須とする

## 4. プライバシー

LINEまたはメールで氏名、連絡先、応募内容、工事相談内容を受け取るため、`/privacy` に次を含むプライバシーポリシーを掲載します。

- 取得する情報
- 利用目的
- 第三者提供
- 安全管理
- 開示・訂正・削除
- 問い合わせ窓口

全ページのフッターからリンクし、協力会社への必要最小限の共有、LINE通話を録音しないこと、不採用者情報を選考終了後に速やかに削除または廃棄することを明記します。

アクセス解析を導入する場合は、利用サービスとCookie等の扱いも追記します。

## 5. アクセシビリティ

- 正しい見出し順とセマンティックなHTMLを使用する
- 画像には用途に合う `alt` を設定し、装飾画像は空の `alt` とする
- キーボード操作時にフォーカス位置が分かるようにする
- 本文と背景は原則4.5:1以上のコントラストを確保する
- 色だけで意味を伝えない
- 主要リンクとボタンは44px × 44px以上を目安にする
- hoverだけに依存しない
- `prefers-reduced-motion` を尊重し、自動アニメーションを実質停止できるようにする

## 6. レスポンシブ・対応環境

スマートフォンを最優先とします。

| 幅              | 用途                         |
| --------------- | ---------------------------- |
| 320px           | 最小幅、はみ出し・重なり確認 |
| 375px           | 基本レイアウト               |
| 390px           | iPhone 14相当                |
| 430px           | 大きめスマートフォン         |
| 768px           | 切り替え地点                 |
| 1024px / 1440px | PC                           |

公開前にiPhone Safari、Android Chrome、PC版ChromeまたはSafariで確認します。

## 7. SEO・共有

- 各ページに固有のtitleとdescriptionを設定する
- OGPは実在する `/images/og-image.jpg` を使用する
- LocalBusiness JSON-LDに固定電話の `telephone` を設定しない
- FAXを構造化する場合は `faxNumber` を使用する
- 本番ドメイン確定後にmetadata、Open Graph、sitemap、robots、JSON-LDのURLを更新する
- 公開後にGoogle Search Consoleへ登録する

## 8. 保守性

- 会社情報は `src/constants/company.ts` に集約する
- 1ファイル1コンポーネントを基本とする
- TypeScriptとTailwind CSSの既存構成を維持する
- 未確定情報をコードや文書で事実として補わない
- 変更後はテスト、Lint、ビルドを実行する
- `AGENTS.md`、README、要件定義、掲載文書が実装と食い違わないように更新する

## 9. 計測

現在の計測イベントは次の通りです。

| イベント    | 対象                                     |
| ----------- | ---------------------------------------- |
| `line_call` | トップContact、採用ApplyのLINE通話       |
| `line_add`  | トップContact、採用ApplyのLINE友だち追加 |
| `email`     | 採用Applyのメール                        |

公開時にCloudflare Web Analyticsを検討し、個人を特定する情報を送らないようにします。
