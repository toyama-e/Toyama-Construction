# 株式会社 外山建設 コーポレートサイト

新潟県三条市・県央地域で土木一式工事、外構工事、改修・修繕、小規模リフォームを行う株式会社外山建設の公式サイトです。

主目的は作業員1名の採用です。工事相談の獲得と、社長・役員を中心に営む小さな会社ならではの親しみやすさを伝えることも目的としています。

## ページ構成

| URL        | 役割                                                                 |
| ---------- | -------------------------------------------------------------------- |
| `/`        | 事業内容、人柄、採用、問い合わせへの簡潔な入口                       |
| `/company` | 3つの強み、会社概要、許可・資格・保険                                |
| `/recruit` | 募集要項、入社後の2つの約束、1日の流れ、中間CTA、代表より、FAQ、応募 |

施工実績は将来追加予定で、現在は実装していません。

## 技術構成

- Next.js App Router / TypeScript
- Tailwind CSS
- 静的エクスポート（`output: "export"`）
- Vitest / Testing Library
- ESLint / Prettier
- Cloudflare Pagesでの公開を予定（未運用）

## デザイン

スマートフォンを最優先とし、ホワイトを主役に、淡いブルーグレー、ネイビー、ブロンズを少量組み合わせます。写真と余白を活かし、見出しにはNoto Serif JP、本文には読みやすいゴシック体を使用します。

## 問い合わせ

優先順位は次の通りです。

1. LINE通話
2. LINEチャット
3. メール

一般公開する固定電話番号はありません。トップページのContactにはLINE通話とLINEチャットを表示し、メールはフッターに控えめなリンクとして表示します。FAX番号を電話番号として扱いません。

## ローカル開発

```bash
npm install
npm run dev
```

同じWi-Fi上のスマートフォンで確認するときは、次のコマンドで起動し、MacのローカルIPアドレスとポート3000をSafariで開きます。

```bash
npm run dev -- --hostname 0.0.0.0
```

## 品質確認
