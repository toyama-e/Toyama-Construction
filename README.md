# 株式会社 外山建設 コーポレートサイト

新潟県三条市で、代表と役員を中心に営む建設会社のコーポレートサイトです。

現場スタッフ1名の採用を主目的に、工事相談の受付と会社の人柄を伝える役割も持たせました。

- **URL:** [https://toyama-kensetsu.com](https://toyama-kensetsu.com)
- **Stack:** Next.js · TypeScript · Tailwind CSS · Cloudflare Pages · Vitest · Google Analytics 4
- **担当:** 要件整理 · 情報設計 · UIデザイン · 実装 · テスト · デプロイ
- **主目的:** 現場スタッフ1名の採用
- **副目的:** 工事相談の獲得、会社の人柄と安心感の可視化

## 設計・実装のポイント

### 本業を妨げない運用設計

少人数で現場業務を行う会社のため、Webサイトの管理や問い合わせ対応が新たな負担にならない構成を重視しました。

### 導入・運用コストの抑制

静的サイトとして構築し、Cloudflare Pagesへデプロイしました。問い合わせ手段をLINE通話・チャット・メールに絞り、導入・運用コストを抑えています。

### 運営者に合わせた問い合わせ導線

日常業務で使い慣れているLINEを中心に設計し、運営者が無理なく問い合わせへ対応できる構成にしました。利用者は通話とチャットを目的に応じて選択できます。

### 採用ターゲットに合わせたデザイン

20〜40代を中心とした現場スタッフ候補を主な閲覧者として想定し、装飾やアニメーションを控えた、情報を素早く確認できるシンプルなデザインにしました。

### 人柄が伝わる情報設計

小さな会社ならではの距離の近さや安心感が伝わるよう、代表と役員の写真やメッセージを掲載しています。

### スマートフォン最優先のレスポンシブ設計

求職者がスマートフォンから閲覧することを想定し、320pxから1440pxまで7種類の画面幅で表示と操作性を確認しました。

### 採用導線の明確化

募集条件、入社後の約束、1日の流れ、代表メッセージ、FAQを独立した採用ページにまとめ、応募前の不安を減らす構成にしています。

## ページ構成

| URL        | 役割                                                                 |
| ---------- | -------------------------------------------------------------------- |
| `/`        | 事業内容、人柄、採用、問い合わせへの簡潔な入口                       |
| `/company` | 3つの強み、会社概要、許可・資格・保険                                |
| `/recruit` | 募集要項、入社後の2つの約束、1日の流れ、中間CTA、代表より、FAQ、応募 |

施工実績は将来追加予定で、現在は実装していません。

## デザイン

スマートフォンを最優先とし、ホワイトを主役に、淡いブルーグレー、ネイビー、ブロンズを少量組み合わせます。写真と余白を活かし、見出しにはNoto Serif JP、本文には読みやすいゴシック体を使用します。

| 用途         | 色        |

| 背景         | `#FFFFFF` |
| 主要CTA      | `#17233A` |

| 区切り背景   | `#F2F7FA` |
| ペールブルー | `#F7FAFC` |
| ライトブルー | `#E7F0F5` |

LINEボタンのみ公式グリーンを使用します。

## 問い合わせ

優先順位は次の通りです。

1. LINE通話
2. LINEチャット
3. メール

一般公開する固定電話番号はありません。トップページのContactにはLINE通話とLINEチャットを表示し、メールはフッターに控えめなリンクとして表示します。FAX番号を電話番号として扱いません。

## ローカル開発

```bash
npm install
npm run dev
```

同じWi-Fi上のスマートフォンで確認するときは、次のコマンドで起動し、MacのローカルIPアドレスとポート3000をSafariで開きます。

```bash
npm run dev -- --hostname 0.0.0.0
```

## 品質確認

```bash
npm test -- --run
npm run lint
npm run build
```

表示確認は375pxを基準に、320px、390px、430px、768px、1024px、1440pxの順で行います。

## アクセス解析・Cookie

Google Analytics 4を使用し、ページ閲覧、流入元、LINE・メール・採用導線のクリックを計測します。本番の測定IDはCloudflare PagesのProduction環境変数で管理します。

日常の確認方法、計測イベント、プライバシー設定、Cookie同意バナーを再検討する条件は [`docs/analytics-operations.md`](docs/analytics-operations.md) を参照してください。
