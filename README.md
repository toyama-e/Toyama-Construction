# 株式会社 外山建設 コーポレートサイト

新潟県県央地区を中心とした土木・外構工事会社の公式コーポレートサイト。  
問い合わせ・採用応募の促進を目的とした1ページ（スクロール型）サイト。

---

## 技術スタック

| 項目           | 採用技術                       |
| -------------- | ------------------------------ |
| フレームワーク | Next.js（静的生成・SSG）       |
| スタイリング   | Tailwind CSS                   |
| 言語           | TypeScript                     |
| ホスティング   | Cloudflare Pages               |
| コード管理     | GitHub                         |
| お問い合わせ   | LINE通話・LINEチャット・メール |
| 地図           | Google Maps Embed API          |

---

## ページ構成

| セクション       | 主なコンテンツ                                         |
| ---------------- | ------------------------------------------------------ |
| ヘッダー         | ロゴ・ナビゲーション・電話ボタン・採用応募ボタン       |
| ヒーロー         | メインビジュアル・キャッチコピー・CTA                  |
| 事業内容         | 外構・改修修繕・リフォーム・公共法人対応（カード形式） |
| 許可・資格・保険 | 建設業許可番号・加入保険・資格一覧                     |
| 会社概要         | 会社情報テーブル＋Googleマップ埋め込み                 |
| 採用情報         | 給与・待遇・1日の流れ・応募ボタン                      |
| お問い合わせ     | LINE通話・LINEチャット・メール                         |
| フッター         | コピーライト・ナビリンク                               |

> 施工実績セクションは **フェーズ2** で追加予定。現時点では実装しない。

## ローカル開発

```bash
npm install
npm run dev    # http://localhost:3000
npm run build  # 本番ビルド確認
```

---

## デプロイ

```
git push → GitHub → Cloudflare Pages が自動ビルド・デプロイ
```

手動操作は不要。

---

## 差し替えが必要な仮データ

- [ ] メールアドレス（現在 `info@example.com`）
- [ ] 建設業許可番号（現在「○○」）
- [ ] 加入保険の正式名称
- [ ] LINE公式アカウントのリンクURL
- [ ] GoogleマップのAPIキー（`.env.local` に設定）
- [ ] ヒーロー背景画像（実際の施工・現場写真）
